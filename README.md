One original funny line for make.fun's "One Line, One Laugh" bounty: a tiny Python program (standard library only) that writes a single hilarious line of at most 200 characters to `entry.txt`, where a judge model compares it pairwise against other entries. The line is a fixed string, so every run produces byte-identical output.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory.

## The line

> I asked my houseplant for advice and it just sat there — honestly the most emotionally available anyone in my family has ever been.

The program holds the line as a constant and asserts it is a single line of 1–200 characters before writing it, so the output is deterministic: run it twice and the file is byte for byte the same.
